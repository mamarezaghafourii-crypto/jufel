# ژوفل

نسخه‌ی آنلاین: https://mamarezaghafourii-crypto.github.io/jufel/

وب‌اپلیکیشن (PWA) برای ثبت سفارش گل، محاسبه‌ی بهای تمام‌شده و قیمت اعلامی به مشتری، با ذخیره در گوگل شیت.

```
index.html  styles.css  app.js  flowers.js  sw.js  manifest.webmanifest
fonts/  icons/
apps-script/
  Code.gs       ← کد اتصال به گوگل شیت
```

## ۱. ساخت گوگل شیت

1. یک Google Sheet تازه بساز.
2. از منوی **Extensions ← Apps Script** همه‌ی کد پیش‌فرض را پاک کن و محتوای `apps-script/Code.gs` را بچسبان.
3. خط `const TOKEN = 'rose-1405';` را به یک رمز دلخواه تغییر بده.
4. تابع **setup** را از بالای ویرایشگر انتخاب و **Run** کن (بار اول اجازه‌ی دسترسی می‌خواهد). دو برگه ساخته می‌شود: «سفارش‌ها» و «قیمت روز».
5. **Deploy ← New deployment ← Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
6. آدرسی که آخرش `/exec` است را کپی کن.

هر بار کد Apps Script را تغییر دادی، از **Deploy ← Manage deployments ← Edit ← New version** نسخه‌ی تازه بده تا آدرس عوض نشود.

## ۲. گذاشتن برنامه روی اینترنت

فایل‌های ریشه‌ی همین ریپو را روی هر هاست استاتیک با **HTTPS** بگذار؛ مثلاً GitHub Pages (ریپوی تازه، آپلود محتوای `app`، بعد Settings ← Pages) یا هاست دامنه‌ی خودت. برای نصب روی آیفون و کار آفلاین HTTPS لازم است.

## ۳. نصب روی آیفون

1. آدرس را در **Safari** باز کن.
2. دکمه‌ی Share ← **Add to Home Screen**.
3. برنامه را از صفحه‌ی اصلی باز کن ← آیکن چرخ‌دنده ← آدرس Web App و رمز را وارد کن ← «بررسی اتصال».

## چطور کار می‌کند

- **سفارش جدید:** اسم مشتری (نام پروژه در شیت) ← گل‌ها با تعداد و قیمت خرید هر شاخه ← بسته‌بندی (باکس، گلدان، کاغذ، سبد) ← ملزومات ← **قیمت‌گذاری**.
- قیمت اعلامی = بهای تمام‌شده × (۱ + درصد سود)، پیش‌فرض ۵۰٪، و رو به بالا گرد می‌شود (پیش‌فرض ۱۰ هزار تومان). هر دو در تنظیمات قابل تغییرند.
- با ذخیره، یک ردیف در برگه‌ی «سفارش‌ها» و یک برگه‌ی جدا به اسم مشتری و تاریخ با ریز اقلام ساخته می‌شود. ویرایش سفارش همان برگه را به‌روز می‌کند.
- اگر اینترنت یا اتصال به گوگل قطع باشد، سفارش روی گوشی می‌ماند (نقطه‌ی نارنجی) و دفعه‌ی بعد خودکار ارسال می‌شود.

## قیمت روز گل‌ها

قیمت هر گل کنار عکسش نشان داده می‌شود و از سه راه به‌روز می‌شود:
1. هر قیمتی که موقع ثبت سفارش وارد می‌کنی، قیمت روز آن گل می‌شود.
2. صفحه‌ی **قیمت روز** در برنامه: صبح‌ها بعد از خرید از بازار، قیمت‌ها را یک‌جا وارد کن.
3. برگه‌ی **قیمت روز** در گوگل شیت: قیمت را همان‌جا بنویس (تاریخش خودکار ثبت می‌شود)؛ برنامه موقع باز شدن آن را می‌خواند.

## عکس گل‌ها

همه‌ی گل‌ها تصویرسازی اختصاصی دارند و بدون اینترنت نمایش داده می‌شوند. روی هر گل بزن و «گذاشتن عکس خودت» را انتخاب کن تا عکس خودت جایگزین شود. گلی که در فهرست نیست را با کاشی «گل دیگر» اضافه کن.

## به‌روزرسانی برنامه

بعد از تغییر هر فایل، در `sw.js` عدد `jufel-v1` را یکی بالا ببر تا آیفون نسخه‌ی تازه را بگیرد.
